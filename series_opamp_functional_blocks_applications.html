1. Introduction and learning objectives

An operational amplifier (op-amp) is a high-gain differential amplifier. Its output responds to the difference between its non-inverting input (+) and inverting input (−). A practical op-amp IC contains several internal stages connected in sequence.

Understand the blocksIdentify the differential input stage, voltage-gain stage, level shifter, and output stage.
Trace the signalFollow a small differential input through the internal amplifier stages.
Use key equationsCalculate closed-loop gain for common op-amp circuits.
Connect to applicationsRecognize amplifiers, buffers, adders, filters, integrators, and comparators.

Prerequisites

Voltage, current, resistance, Ohm’s law, Kirchhoff’s laws, basic transistor operation, feedback, and RC circuits.

Important terminology

TermMeaning
Differential inputThe voltage difference between the + and − terminals: \(v_d=v_+-v_-\).
Open-loop gainGain with no feedback; usually very large.
Negative feedbackA fraction of the output is returned to the inverting input to set predictable closed-loop behaviour.
Input impedanceHow much the input resists drawing current; ideally infinite.
Output impedanceEffective impedance seen looking back into the output; ideally zero.
Common-mode signalA signal that appears equally at both inputs and ideally is rejected.
Terminology note: “Series op-amp” is not a universally standard name for one particular circuit. This page interprets it as the series-connected internal functional blocks of an op-amp. If a course uses “series op-amp” to mean a specific circuit, its circuit diagram or IC number is needed to identify it exactly.

3. Working principle: step by step

  1. Apply two input voltages. The input stage senses \(v_d=v_+-v_-\), not simply one input alone.
  2. Convert the difference into an internal signal. The differential pair steers current according to the input difference.
  3. Build voltage gain. The intermediate stage amplifies the signal substantially.
  4. Adjust the DC level. The level-shifting circuitry establishes a suitable bias level for the output stage.
  5. Drive the load. The output stage supplies or sinks current within the IC’s voltage and current limits.
  6. Use feedback for predictable operation. In most linear applications, negative feedback sets the gain and improves linearity.

Ideal op-amp assumptions with negative feedback

i+ ≈ i− ≈ 0    and    v+ ≈ v− Valid approximation for an ideal op-amp operating linearly with effective negative feedback; it is not a universal rule in open-loop/comparator operation.

Open-loop versus closed-loop

FeatureOpen-loopClosed-loop with negative feedback
GainExtremely high, poorly controlledSet mainly by external components
Typical useComparator-like operationLinear amplification, filtering, integration

Practical limits: Real op-amps have finite gain and bandwidth, input offset voltage, input bias currents, slew-rate limits, noise, finite common-mode range, and output swing/current limits. Check the datasheet.

4. Essential equations

Basic open-loop relation

vout = Aol (v+ − v−)Aol is open-loop voltage gain (dimensionless). Actual output is limited by the supply rails and output-stage capability.

Inverting amplifier

Av = vout / vin = −Rf / RinIdeal op-amp, negative feedback, and operation away from saturation. The minus sign means 180° phase inversion.

Non-inverting amplifier

Av = vout / vin = 1 + (Rf / Rg)Output is in phase with input. Input impedance is ideally very high.

Voltage follower (buffer)

Av ≈ 1    ⇒    vout ≈ vinUseful for impedance matching; it does not ideally amplify voltage.

Summing amplifier (inverting)

vout = −Rf (v1/R1 + v2/R2 + … + vn/Rn)For equal input resistors R and feedback resistor Rf: vout = −(Rf/R)(v1+v2+…+vn).

Decibels and bandwidth

Gain (dB) = 20 log10 |Av|For voltage gain, use the magnitude. A gain magnitude of 10 corresponds to 20 dB.
For a dominant-pole op-amp: GBW ≈ |Acl| × fBWApproximate gain-bandwidth product; check the datasheet and stability conditions.

5. Solved numerical examples

Example 1 — Inverting amplifier

Given: \(R_{in}=10\,k\Omega\), \(R_f=100\,k\Omega\), \(v_{in}=0.20\,V\). Find gain and output.

  1. Use \(A_v=-R_f/R_{in}\).
  2. \(A_v=-100/10=-10\).
  3. \(v_{out}=A_vv_{in}=-10(0.20)=-2.0\,V\).
Answer: Gain = −10 V/V; output = −2.0 V, assuming the op-amp can swing to that voltage.

Example 2 — Non-inverting amplifier

Given: \(R_f=30\,k\Omega\), \(R_g=10\,k\Omega\), \(v_{in}=0.5\,V\).

  1. \(A_v=1+R_f/R_g\).
  2. \(A_v=1+30/10=4\).
  3. \(v_{out}=4(0.5)=2.0\,V\).
Answer: Gain = 4; output = 2.0 V, provided the supply and output swing allow it.

Example 3 — GATE-style gain and dB

Given: An ideal non-inverting amplifier has \(R_f=40\,k\Omega\) and \(R_g=10\,k\Omega\). Find its voltage gain and gain in dB.

  1. \(A_v=1+40/10=5\).
  2. \(G_{dB}=20\log_{10}(5)\).
  3. \(G_{dB}\approx 13.98\,dB\).
Answer: Voltage gain = 5 V/V; gain ≈ 14 dB.

6. Applications and industry relevance

Signal amplificationAmplifies small sensor signals before digitization, subject to noise and input-range limits.
Voltage followerBuffers a high-impedance sensor so a later stage does not load it heavily.
Summing amplifierCombines weighted signals in audio mixers, analog computation, and conditioning circuits.
Active filtersWith resistors and capacitors, forms low-pass, high-pass, and band-pass filters.
Integrator / differentiatorPerforms time-domain analog operations; practical circuits add components to control drift and noise.
Comparator / threshold detectionCompares signals in some simple applications, although a dedicated comparator is often better for switching.
Instrumentation and measurementOp-amps form parts of sensor front ends, bridge interfaces, and measurement systems.
Control systemsUsed in error amplifiers, feedback controllers, and analog signal-conditioning loops.

Practical design checklist

  • Supply voltage and input common-mode range.
  • Output swing and required load current.
  • Gain-bandwidth product and slew rate.
  • Input offset, bias current, noise, and temperature drift.
  • Capacitive-load stability, decoupling, grounding, and PCB layout.
  • For safety-critical or patient-connected equipment, use appropriate isolation and standards-compliant design.

Advantages and limitations

AdvantagesLimitations
Flexible circuits using a small number of external components.Finite bandwidth, gain, slew rate, and output current.
Negative feedback gives predictable gain.May oscillate if feedback/layout or capacitive loads are not handled correctly.
High input impedance and low output impedance are achievable.Input/output voltage ranges depend on the selected device and supply.

8. Core electronics interview questions

1. Why is the input stage differential?

It responds to the difference between two input voltages and ideally rejects a voltage common to both inputs. This improves common-mode noise rejection.

2. Which block provides most of the voltage gain?

The intermediate voltage-gain stage typically provides most of the op-amp’s open-loop voltage gain.

3. What is the purpose of a level shifter?

It shifts the DC operating level between internal stages so the output stage can operate around its intended quiescent point.

4. Why does an op-amp need an output stage?

It provides lower output impedance and the current needed to drive a load, within device limits.

5. What is virtual short?

With effective negative feedback and linear operation, the two input voltages are approximately equal. They are not physically shorted together.

6. Why does an open-loop op-amp often saturate?

Its open-loop gain is very high, so even a small differential input can demand an output beyond the available supply range.

7. How would you troubleshoot an output stuck at a supply rail?

Check input polarity and common-mode range, feedback wiring, supply pins, reference/ground, output loading, and whether the requested output exceeds the available swing.

8. What is gain-bandwidth product?

For a common dominant-pole op-amp, closed-loop gain magnitude multiplied by bandwidth is approximately constant over the applicable range.

9. Why can a circuit oscillate after adding a capacitor at the output?

Capacitive loading can change loop phase and reduce phase margin. Use a device suited to the load or a datasheet-recommended isolation method.

10. When is an instrumentation amplifier preferred?

When accurate differential measurement, high input impedance, and strong common-mode rejection are required; it may contain several op-amp stages internally.

11. What should be checked before selecting an op-amp for a sensor?

Input common-mode range, offset, bias current, noise, bandwidth, supply range, output swing, current, and temperature performance.

12. Why use a voltage follower?

It provides near-unity voltage gain while isolating a high-impedance source from a lower-impedance load.

10. Quick revision sheet

Remember the block order

Differential input → Voltage-gain stage → Level shifter → Output stage

Key points

  • The differential input stage senses \(v_+-v_-\).
  • The intermediate stage gives most of the voltage gain.
  • The level shifter sets a suitable DC level between stages.
  • The output stage drives the load.
  • Negative feedback makes closed-loop gain depend mainly on external components.
  • “Virtual short” is an approximation only under linear negative-feedback conditions.
  • Always verify supply range, common-mode range, output swing, bandwidth, and load capability.

Common errors

Common mistakeCorrection
Assuming input terminals are physically connected.They are approximately at equal voltage under suitable negative feedback, but input current is ideally near zero.
Forgetting the minus sign in an inverting amplifier.\(A_v=-R_f/R_{in}\); output is inverted.
Assuming output can reach the supply rails.Output swing depends on the op-amp and load; rail-to-rail behaviour is device-specific.
Using an op-amp as a comparator without checking suitability.Dedicated comparators are generally designed for faster switching and defined output behaviour.
